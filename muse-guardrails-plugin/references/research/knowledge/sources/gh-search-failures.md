- BUG labels include fixes, controls and capability gaps; preserve the attribution in each quotation citation. PR merged/closed state is not inferred. Missing original authors prevent verified unique-reporter counts.
- Search body excerpts are truncated and not full issue threads. Some duplicate the per-repository notes or mirrored issues; do not infer final resolution or additional reporters.
- gh-search-failures.txt: TSV body excerpts only, not complete threads; duplicate issue IDs/full-thread captures count once. More than ~40 bullets retained because the addendum explicitly requests every relevant failure. Unattributed issue bodies do not establish independent human reporter identities.
