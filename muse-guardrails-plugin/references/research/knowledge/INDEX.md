# Muse knowledge base index

Analyzed from [evidence.md](../evidence.md), not raw capture dumps. Each usable non-GitHub capture has one note; full GitHub issue/PR captures are grouped by repository. The GitHub search compilation remains a separate excerpt note and does not add independent reporters to duplicate issues. HN threads remain separate. Sparse usable sources are retained with explicit evidence ceilings. Empty/blocked and zero-substantive-evidence captures are excluded.

Grades: A = Meta on its own product; B = independent measurement; C = detailed journalism/practitioner/researcher evidence; D = unsupported assertion/marketing. Grades describe provenance, not guarantees of truth.
