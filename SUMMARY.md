## Muse

Every new skill has an `adapters/muse.md` with Muse Code install steps, a tool mapping, and Muse run rules tied to the failure modes in `muse-guardrails-plugin/references/research/report.md`. The core `SKILL.md` still works on every other host. To install one skill in Muse Code, run `muse skills install ./<skill> --scope user`, or copy the folder to `~/.agents/skills/<skill>/`. Then add the 1 `AGENTS.md` line its adapter gives, because Muse Code may not surface project skills on its own.

Where a generic skill and a Muse guardrail share a topic, they split the work: the generic skill holds the script, and its adapter sends Muse runs to the guardrail too. The pairs are `benchmark-skepticism` + `muse-benchmark-skepticism`, `pii-minimization-before-send` + `muse-privacy-minimization`, and `untrusted-content-quarantine` + `muse-injection-hygiene`.
